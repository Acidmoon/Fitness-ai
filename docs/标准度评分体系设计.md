# 标准度评分体系设计

本文档记录当前后端标准度评分的工程口径，避免后续动作规则扩展时只返回一个不可解释的总分。

## 第一性原理结论

标准度评分要回答的不是“分数是多少”，而是“哪些可复现证据支撑这个分数”。因此评分结果必须同时保留总分、次数、置信度、阶段证据和维度化扣分项。

当前为 `standard_quality_v2`，保留六个维度的解释，但关键帧置信度作为采集证据，不参与动作标准度总分：

| 维度 | 基础权重 | 主要证据 |
| --- | --- | --- |
| 关节角度 | 25% | 最低点角度、最高点角度、是否形成完整周期 |
| 身体直线度 | 20% | 俯卧撑肩-髋-踝链路相对 180 度的平均偏差；深蹲不适用 |
| 动作幅度 | 20% | 关节角度最大值与最小值的行程 |
| 节奏稳定性 | 15% | 至少两次有效重复持续时间的变异系数 |
| 左右对称性 | 10% | 左右同名关节角度差 |
| 关键帧置信度 | 0% | 有效次数关键帧或全有效帧平均置信度，单独展示 |

基础权重合计 90%，实际权重按已评维度重新归一化，合计 100%。`not_applicable` 不计入适用覆盖分母；`unassessed` 表示缺失证据，计入分母且使评估为 `partial`。零有效次数的总分仍封顶 70。

## 响应结构

顶层 `score` 是 0-100 分，`count` 是自动有效次数。只有 `assessment_status=complete` 才允许应用到记录，`partial` 分数仅可预览。以下片段展示缺失身体链时的证据语义，省略其他维度与实际权重：

```json
{
  "metrics": {
    "quality": {
      "version": "standard_quality_v2",
      "assessment_status": "partial",
      "dimensions": {
        "body_alignment": {
          "score": null,
          "status": "unassessed",
          "metrics": {"neutral_reason": "缺少肩髋踝完整关键点，身体直线度未评估"},
          "feedback": []
        }
      }
    }
  }
}
```

## 工程边界

- 本文件只定义“总分怎么拆成六个维度”；**每个动作用什么角度算到位**属于动作标准，
  见 `docs/动作评分标准.md`（含官方口径、生效阈值与容差理由）。
- 基础权重是全局的，实际权重随适用性和证据变化；维度内部判据来自规则默认值或目录行 `pose_scoring` 覆盖，
  因此同一个 82 分在不同 `rule_version` 下不等价，展示与统计都需携带版本号。

- `pose_features.py` 只提供通用几何特征，例如关节角、身体直线度和左右对称性，不写动作专属阈值。
- `exercise_rules/<action>.py` 继续负责动作关键点组合、阶段检测和次数统计阈值。
- `pose_scoring_engine.py` 组合通用特征、规则、阶段与可解释评分；`exercise_pose_scoring.py` 处理记录来源及应用快照。
- 缺少必要关键点时返回 `score=null` 与 `status=unassessed`，在 `metrics.neutral_reason` 说明原因；不能按 100 分填补。动作或样本不适用的维度返回 `not_applicable`。
- `video_quality_v2` 先检查有效帧数和有效帧比例（低于 60% 拒评）；平均置信度仍独立展示和提示。阈值是工程门槛，真实样本校准尚未完成。
- `coverage` 是已评权重除以适用基础权重，不表示识别准确率；当前尚未实现按机位自动识别维度适用性。

## 后续扩展

新增动作时先明确每个维度是否适用，再声明所需证据与缺失策略；不得为了输出总分而给不可测维度满分。新质量版本改变总分语义，不能与 `standard_quality_v1` 混合比较。
