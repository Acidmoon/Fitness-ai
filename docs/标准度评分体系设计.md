# 标准度评分体系设计

本文档记录当前后端标准度评分的工程口径，避免后续动作规则扩展时只返回一个不可解释的总分。

## 第一性原理结论

标准度评分要回答的不是“分数是多少”，而是“哪些可复现证据支撑这个分数”。因此评分结果必须同时保留总分、次数、置信度、阶段证据和维度化扣分项。

当前实现把总分拆成六个维度：

| 维度 | 权重 | 主要证据 |
| --- | --- | --- |
| 关节角度 | 25% | 最低点角度、最高点角度、是否形成完整周期 |
| 身体直线度 | 20% | 肩-髋-踝链路相对 180 度的平均偏差 |
| 动作幅度 | 20% | 关节角度最大值与最小值的行程 |
| 节奏稳定性 | 15% | 有效次数持续时间的变异系数 |
| 左右对称性 | 10% | 左右同名关节角度差 |
| 关键帧置信度 | 10% | 有效次数关键帧或全有效帧平均置信度 |

## 响应结构

顶层 `score` 仍表示最终可应用到训练记录的 0-100 分，`count` 仍表示 AI 自动估算的有效次数。新增的维度证据放在 `metrics.quality`：

```json
{
  "score": 82.5,
  "count": 12,
  "confidence": 0.84,
  "metrics": {
    "quality": {
      "version": "standard_quality_v1",
      "score": 82.5,
      "weights": {
        "joint_angle": 0.25,
        "body_alignment": 0.2,
        "movement_range": 0.2,
        "rhythm_stability": 0.15,
        "left_right_symmetry": 0.1,
        "keyframe_confidence": 0.1
      },
      "dimensions": {
        "joint_angle": {"score": 100, "metrics": {}, "feedback": []}
      }
    }
  }
}
```

## 工程边界

- `pose_features.py` 只提供通用几何特征，例如关节角、身体直线度和左右对称性，不写动作专属阈值。
- `exercise_rules/<action>.py` 继续负责动作关键点组合、阶段检测和次数统计阈值。
- `exercise_pose_scoring.py` 负责把通用特征、动作规则、阶段摘要组合成可解释评分响应。
- 当某个维度缺少必要关键点时，该维度按中性分处理，并在 `metrics.neutral_reason` 中说明原因，避免旧关键点数据被误扣。

## 后续扩展

新增动作时优先复用现有六维结构。只有当动作本质上不适合周期计数或肩-髋-踝链路时，才为该动作新增专属维度或把维度标记为中性。
